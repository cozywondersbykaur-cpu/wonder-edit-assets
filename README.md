# The Wonder Edit: Brand Kit

## Files
| File | Use it for |
|---|---|
| `logo.png` | Logo with a transparent background: Kit sign-up page, anywhere on a light background |
| `logo-email-header.png` | Top of every newsletter email (cream background, padded) |
| `instagram-profile.png` | Instagram profile picture (safe for the circle crop) |
| `logo.svg` / `icon.svg` | Master files: scale to any size without blurring (give these to a printer or designer) |

## Colours
| Name | Hex | Use |
|---|---|---|
| Sunshine | `#FFC43D` | Icon circle, highlights, backgrounds |
| Coral | `#F2604A` | The sparkle, "Edit", buttons |
| Teal | `#1E9E93` | Small sparkle, accents, links |
| Ink | `#22304A` | Headings and body text |
| Cream | `#FFF8EC` | Page and email background |

## Font
**Fredoka** (free from Google Fonts). SemiBold for headings, Regular for body text.
In Kit, if Fredoka isn't available, use a clean sans-serif (e.g. Helvetica/Arial) for body text and keep the logo image for the header.

## The idea
The sparkle is the "wonder": the little moment of discovery in play. Warm sunny yellow and coral feel friendly and energetic; navy text keeps it calm and trustworthy for parents.

## Do / Don't
- Do keep space around the logo (at least the height of the word "the").
- Do use the logo on white or cream. On photos, use the sparkle icon alone.
- Don't stretch, recolour, or add shadows to the logo.
